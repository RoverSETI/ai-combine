## Скрипты-утилиты «не работают» — две типовые причины (исправлены 07.11)
1. **HTML-сущности от копирования из веба**: `&amp;&amp;` вместо `&&`, `&lt;` вместо `<`,
   `&gt;` вместо `>` — bash падает «рядом с неожиданным маркером». Лечение:
   разворот сущностей: `sed 's/&gt;/>/g; s/&lt;/</g; s/&amp;/\&/g' файл.sh`
2. **CRLF-переносы** (Windows-файл): ошибка `$'{\r'` — конвертация: `dos2unix файл.sh`
   или python `replace(b'\r\n', b'\n')`
- системные утилиты обслуживания — переписаны и протестированы живьём 07.11
  (описание — в их локальных README, в Git не публикуются)
