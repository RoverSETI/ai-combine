# Запуск и порты

## Сервисы

| Порт | Сервис | Запуск из |
|---|---|---|
| 8080 | Open WebUI (веб-интерфейс) | AI-Combine/OpenWebUI-Local/.venv |
| 8081 | Роутер llama-server (CUDA 13, models-preset) | AI-Combine/llama-cuda13/llama-server |
| 8082 | Эмбеддинги gte-modernbert | AI-Combine/AiStart (RAG, семантический поиск) |
| 8089 | MCP local-tools (32 инструмента) | AI-Combine/AiStart/mcp_server.py |
| 8135 | Мост GIMP-MCP | mcp-gimp |
| 8136 | Мост Inkscape-MCP | mcp-inkscape |
| 27123 | Obsidian Local REST API — только при открытом приложении Obsidian | плагин |

## Порядок

```bash
~/AiStart/start_ai.sh    # поднимает всё, ждёт health каждого, прогревает конвейер
~/AiStart/stop_ai.sh     # мягкая остановка по PID-файлам, SIGKILL выжившим
~/AiStart/status_ai.sh   # статус + VRAM
```

## Health-проверки

```bash
curl http://127.0.0.1:8080/health                       # WebUI
curl http://127.0.0.1:8081/v1/models                    # роутер: 7 моделей
curl -X POST http://127.0.0.1:8089/mcp -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"t","version":"1.0"}}}'
```

## Нюансы

- **ulimit -n 8192** задан в start_ai.sh: дефолтный 1024 рвал RAG-батчи Знаний
  («Too many open files» — файлы молча не привязывались к базе)
- `WEBUI_AUTH=False`, только OpenAI-протокол (ollama выключен), фоновые генерации
  заголовков/тегов выключены — роутер не дёргается лишними запросами
- Модели грузятся в VRAM по требованию (`--models-max 1`): переключение роли ~10–30 с
- При тестах рисования/STT сначала выгрузить LLM: MCP `ai_unload all`
