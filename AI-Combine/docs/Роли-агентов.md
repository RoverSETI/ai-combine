# Роли агентов (роутер :8081)

Конфиг: `AI-Combine/AiStart/agents.json` (роли + маршрутизация по ключевым словам),
модели — `AI-Combine/AiStart/models.ini` (ctx, кванты KV, mmproj).

| Роль | Модель | ctx | tools | Назначение |
|---|---|---|---|---|
| fast | qwen2.5-coder-0.5b | 2048 | — | односложные ответы, прогрев VRAM |
| medium | qwen2.5-coder-7b | 32768 | — | рутина: тексты, переводы, пояснения |
| hard | qwen3.5-9b-instruct | 49152 | ✅ | сложный анализ, многошаговые агенты |
| mini | qwen3-4b-instruct-2507 | 12288 | ✅ | быстрые агентские задачи (в ~2.5× быстрее hard) |
| coder | qwen2.5-coder-7b | 32768 | — | чистый код |
| vision | nvidia-nemotron-12b-vision | 32768 | — | изображения, скриншоты |

- llama-3.1-8b **исключён из ролей**: квант вырожден (tool-call JSON на любой вопрос)
- qwen3.5-9b — reasoning-модель: в коротких ответах использовать
  `chat_template_kwargs: {"enable_thinking": false}` или generous max_tokens
- маршрутизация: vision → coder → fast → mini → hard → medium (по ключевым словам, конфиг routing)

## Модели в VRAM

`--models-max 1`: одна модель одновременно. Переключение ~10–30 с.
MCP-инструменты: `ai_status`, `ai_load <роль>`, `ai_unload all` (перед рисованием/STT).
