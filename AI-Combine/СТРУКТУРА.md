# AI-Combine — единая папка ИИ-комбайна (создана 07.11.2026)

Все компоненты комбайна собраны в одну папку. **Старые пути работают** через
симлинки-алиасы в `/home/rover/` — ни один скрипт/конфиг не пришлось править.

## Структура

| Папка | Что внутри | Как используется |
|---|---|---|
| `AiStart/` | Главный стек: `start_ai.sh` / `stop_ai.sh` / `status_ai.sh`, `mcp_server.py` (MCP :8089, 32 инструмента), `swarm_tools.py` (web/glm/stt/рисование), `agents.json` (роли роя), `models.ini` (пресеты роутера, ctx 49152), `habr_*.py` (Хабр-конвейер), ключи `ZaiKey`/`PolzaKey>Z.ai` | `~/AiStart/start_ai.sh` (симлинк) |
| `SwarmConfig/` | Мастер-конфиги роя: `swarm.json`, `mcp_local.json`, `stt.json`, генератор `gen_swarm_tools.py`, `apply_swarm.sh`, `fix_vault_paths.sh`, инструкции, `functions/context_compressor.py` | политика «конфиги в SwarmConfig» |
| `OpenWebUI-Local/` | Open WebUI + `.venv` + `data/` (БД чатов, векторная база) + `scripts/` (sync_knowledge.py, e2e-тесты) | http://localhost:8080 |
| `giga_speech/` | GigaAM-v3 STT: веса `model/` (~450 МБ), `stt_model.py`, `file_transcribe.py` | транскрибация (MCP stt_transcribe) |
| `sd.cpp/` | stable-diffusion.cpp + FLUX (рисование, ~18 с) | MCP image_generate |
| `AI-Models/` | Все GGUF-модели (53 ГБ): Qwen3.5-9B, qwen2.5-coder-*, Nemotron-VL, Llama-3.1 | models.ini |
| `llama-cuda13/` | Прод-сборка llama-server (CUDA 13) | роутер :8081 |
| `llama/`, `build-llama/` | Старые сборки llama.cpp (Vulkan/исходники) — «возможные, не проверенные» | резерв |
| `mcp-gimp/`, `mcp-inkscape/` | Мосты MCP → GIMP/Inkscape (мост :8135 / :8136) | рисование в редакторах |

## Запуск / остановка / статус

```bash
~/AiStart/start_ai.sh     # старт всего стека (роутер, эмбеддер, MCP, мосты, WebUI)
~/AiStart/stop_ai.sh      # остановка
~/AiStart/status_ai.sh    # статус
```
