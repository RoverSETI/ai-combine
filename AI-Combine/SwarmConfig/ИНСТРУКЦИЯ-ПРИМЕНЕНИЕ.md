## ЧАСТЬ 3. ЗНАНИЯ ИЗ OBSIDIAN: три канала доступа

Ваши собранные заметки (`/home/rover/GoogleDrive/Obsidian`, 62 файла в базе) доступны рою и мне **тремя каналами**. У каждого — своя задача.

### Канал А. Прямое чтение файлов (grep) — точный и мгновенный
Vault — обычная папка на диске. Любой агент (и я в терминале) может:
```bash
# точное слово/фразу по всему vault:
grep -rn "inxi" /home/rover/GoogleDrive/Obsidian --include="*.md" -l
# с контекстом:
grep -rn -A 3 "Какая команда в Manjaro" /home/rover/GoogleDrive/Obsidian --include="*.md"
```
**Когда использовать:** ищем точный термин, имя команды, файл, тег `[[wiki-link]]`. Мгновенно, без сервисов.

### Канал Б. Семантический поиск WebUI (RAG) — «по смыслу»
62 заметки проиндексированы (эмбеддер gte-modernbert, гибридный поиск). Запрос словами «о чём заметка», даже без точных слов:
```bash
TOKEN=$(cat /tmp/webui_jwt.txt)   # см. ЧАСТЬ 4, если истёк
curl -s -X POST http://127.0.0.1:8080/api/v1/retrieval/query/collection \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"collection_names":["dfe4a423-90f1-4db7-909c-206d599b8f58"],
       "query":"как посмотреть логи системы","k":3}'
```
Ответ: `documents` (кусочки заметок), `metadatas` (имя файла-источника).
**Когда использовать:** «что я писал про…», тема без точного термина, сводки по нескольким заметкам. В чате WebUI это делается автоматически (модель obsidian-knowledge вызывает поиск сама).

### Канал В. MCP Obsidian (:27123) — чтение+ЗАПИСЬ, требует запущенного Obsidian
Плагин Local REST API работает только при открытом приложении Obsidian. Используется для записи заметок агентами (конспекты Habr, результаты задач). Для простого чтения каналы А/Б быстрее.

### Правило выбора канала
```
Знаю точное слово/файл?  → Канал А (grep)
Ищу по смыслу/теме?      → Канал Б (RAG)
Нужно ЗАПИСАТЬ?          → Канал В (MCP Obsidian, Obsidian должен быть запущен)
```

## ЧАСТЬ 4. КАК Я (ZCode) ПОЛЬЗУЮСЬ ВАШИМИ ЗНАНИЯМИ

Я работаю в терминале вашей машины и подключаюсь к знаниям так:

1. **При старте сессии** я вспоминаю из постоянной памяти: «у пользователя есть vault с собранными для меня знаниями и база Знаний в WebUI» — указатели лежат в `memory/` (это не конфиги, это ссылки на ваши ресурсы).
2. **Перед ответом на тематический вопрос** проверяю vault:
   - сначала grep по ключевым словам задачи (канал А, ~1 секунда);
   - если тема размытая — семантический запрос к базе (канал Б, curl выше).
3. **Найденное использую как контекст**: цитирую заметку, опираюсь на вашу конфигурацию (например, заметка «AI manjaro» с конфигурацией RTX 3060 уже помогала мне при диагностике).
4. **Записи, которые вы собираете для меня**, подхватываются циклом: вы кладёте `.md` в vault → запускается `~/OpenWebUI-Local/scripts/load_knowledge.py` → база переиндексирована → заметка доступна и мне (А/Б), и рою агентов в чате, и модели obsidian-knowledge.
   ⚠️ Повторная загрузка старых файлов даёт безвредную ошибку «Duplicate content» — новые заметки при этом загружаются.
5. **Если JWT истёк** (ошибка 401): новый токен генерируется из секрета работающего сервера — процедура описана в моей памяти (`openwebui-knowledge-setup`), либо просто зайдите в WebUI браузером и создайте API-ключ (Настройки → Аккаунт) — его можно подставлять вместо JWT.

**Пример реального цикла (уже происходило):**
Вы: «Почему тормозит система?» → я: grep по vault «тормозит|производительность» → нахожу «Оптимизация производительности TuneD в Manjaro» → читаю → опираюсь на ваши выводы, а не на общие догадки.

## ЧАСТЬ 6. ДИАГНОСТИКА

| Симптом | Причина | Действие |
|---|---|---|
| web_search отдал «капчу» | DDG ограничил частоту | Подождать минуту, переформулировать |
| glm_* HTTP 401 | Ключ в PolzaKey>Z.ai неверен/истёк | Обновить файл, проверить лимиты z.ai |
| glm_* «лимит исчерпан» | 20 вызовов/день | Завтра или поднять лимит в swarm_tools.py (строка GLM_DAILY_LIMIT) |
| stt «CUDA out of memory» | В VRAM висит 9B-модель | Сначала `ai_unload all` |

| 401 на запросах к WebUI API | JWT истёк | Заново создать токен или API-ключ из UI |
| Инструменты не появились в WebUI | MCP не перезапустился | `~/SwarmConfig/apply_swarm.sh rollback` → apply заново; смотреть `~/AiStart/logs/mcp_server.log` |
| image_generate «свободно N MiB» | В VRAM висит LLM | `ai_unload all` → повторить (18 с/картинка) |
| glm_* HTTP 402 | Баланс polza исчерпан | Пополнить баланс polza.ai — инструменты вернут ошибку честно |
