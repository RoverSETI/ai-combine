## Симлинки-алиасы

`AiStart`, `SwarmConfig`, `OpenWebUI-Local`, `giga_speech`, `sd.cpp`, `AI-Models`,
`llama-cuda13`, `llama`, `build-llama`, `mcp-gimp`, `mcp-inkscape` — все указывают
на `AI-Combine/<имя>`. На новой машине пересоздаются одной строкой:

```bash
for d in AiStart SwarmConfig OpenWebUI-Local giga_speech sd.cpp AI-Models llama-cuda13 llama build-llama mcp-gimp mcp-inkscape; do ln -sfn "/home/rover/AI-Combine/$d" "/home/rover/$d"; done
```
